# Console Graphics (Python)

A lightweight, real-time 3D graphics engine that renders directly in your terminal using ANSI escape codes and `pynput` for keyboard input.

## Prerequisites

- Python 3.8 or higher
- Linux/macOS/Windows Terminal (supports ANSI escape sequences)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ORBITUMS/console-graphic-py.git
   cd console-graphic-py
   ```
